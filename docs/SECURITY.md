# Security notes

**Authentication**
- Supabase Auth, with cookie sessions refreshed in `src/proxy.ts`.
- Server code identifies users with `auth.getClaims()`, which verifies the JWT.
- Redirects after login are restricted to same-site paths.

**Authorisation**
- Every admin page calls `requireStaffPage()`, and every admin action calls `adminContext(roles)`. These read roles from `user_roles` on the server.
- The database then enforces the same rules again through RLS (`is_staff()` / `is_admin()`) and security-definer functions that check roles themselves.

**RLS**
- Enabled on every table.
- Customers can read only their own orders, payments, addresses, wishlist and support requests.
- Coupons, inventory movements and webhook events are hidden from customers.
- Column grants stop users from changing profile fields other than name and phone, review status, rating aggregates and coupon usage counts.

**Service role** is used only in trusted server code, where the call needs it:
- `place_order` and payment and refund functions, which are granted to `service_role` only
- webhooks
- anonymous view counting
- newsletter sign-up
- coupon lookup

Each of these runs after its own validation or authorisation. The key is read from a `server-only` module.

**Money**
- Integer paise everywhere.
- The browser never supplies a price, discount or total.
- The database re-checks unit prices and totals.

**Uploads**
- Admin-only.
- Limited to 5 MB.
- The file type is checked from its magic bytes (JPEG, PNG, WebP, AVIF; no SVG).
- Object names are generated by the server, and the bucket MIME allow-list is enforced by Storage too.

**Other protections**
- Rate limits on sign-in, sign-up, password reset, checkout, payment, contact, newsletter, reviews, search and view tracking.
- CSV export neutralises formula injection.
- Security headers are set in `next.config.ts`.

**Logging**
- Errors log codes and order numbers only.
- Never payloads, secrets, full emails or payment details.

**Privacy**
- Product-view counting stores only a salted daily hash.
- "Recently viewed" lives in the visitor's own browser.
